# Atlas Autopilot

Producción automática de shorts para **Atlas del saber**: investigación (Metricool + vidIQ), guion, voz Hache,
animación, música, efectos y propuesta de publicación. Nada se publica sin tu aprobación.

- `PIPELINE.md` — el ciclo completo paso a paso.
- `eng/` — motor de animación y sonido.
- `datos/` — temas publicados, banco de ideas y videos pendientes de aprobar.
- `videos/` — una carpeta por video (fuentes; los MP4 se alojan en la rama `media`).
